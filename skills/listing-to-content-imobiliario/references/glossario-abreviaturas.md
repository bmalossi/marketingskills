# Glossário de Abreviaturas — Fichas de Imóvel

Referência para interpretar e humanizar fichas técnicas de imóveis em copy e conteúdo.

---

## Abreviaturas de Tipologia

| Abreviatura | Significado |
|-------------|-------------|
| `apto` / `apt` | Apartamento |
| `cs` / `casa` | Casa |
| `terra` / `terr` | Terreno |
| `sl` / `sala` | Sala comercial |
| `loja` | Loja comercial |
| `kitnet` / `kit` | Kitnet (studio) |
| `cobert` | Cobertura |
| `conj` | Conjunto (comercial) |
| `flat` | Flat / Apart-hotel |

---

## Abreviaturas de Dormitórios e Banheiros

| Abreviatura | Significado |
|-------------|-------------|
| `2d` / `2 dorm` | 2 dormitórios |
| `3d` / `3q` | 3 dormitórios / 3 quartos |
| `1s` / `1 suíte` | 1 suíte |
| `2s` | 2 suítes |
| `bwc` | Banheiro |
| `wc social` | Banheiro social (não é suíte) |
| `lav` / `lavabo` | Lavabo |

---

## Abreviaturas de Vagas e Garagem

| Abreviatura | Significado |
|-------------|-------------|
| `1vg` / `1g` | 1 vaga de garagem |
| `2vg` | 2 vagas de garagem |
| `coberta` | Vaga coberta |
| `descoberta` | Vaga ao tempo |
| `box` | Box de garagem individual |

---

## Abreviaturas de Metragem

| Abreviatura | Significado |
|-------------|-------------|
| `m²` | Metro quadrado (área útil) |
| `área total` | Área total construída (inclui partes externas) |
| `área privat` | Área privativa (apenas do apartamento) |
| `área comum` | Área de uso coletivo do condomínio |

---

## Características do Imóvel

| Abreviatura/Termo | Significado |
|-------------------|-------------|
| `AP` / `arm plan` | Armários planejados |
| `coz amer` | Cozinha americana (integrada à sala) |
| `HO` / `home off` | Dependência de home office |
| `DCE` | Dependência completa de empregada |
| `vara` / `varanda` | Varanda |
| `var gourm` | Varanda gourmet (com estrutura para churrasco) |
| `lazer comp` | Lazer completo (piscina, academia, churrasqueira, etc.) |
| `pisç` / `piscina` | Piscina |
| `acad` | Academia / sala de ginástica |
| `sl fest` | Salão de festas |
| `sl jogas` | Salão de jogos |
| `qd tênis` | Quadra de tênis ou esportes |

---

## Condições de Venda / Jurídico

| Termo | Significado |
|-------|-------------|
| `financia` | Aceita financiamento (Caixa, banco) |
| `ac FGTS` | Aceita uso do FGTS como pagamento ou entrada |
| `ac troca` | Aceita permuta/troca por outro imóvel |
| `escriturad` | Imóvel com escritura lavrada em cartório |
| `av registr` | Averbação registrada no cartório |
| `ITBI pago` | Imposto de Transmissão de Bens Imóveis já pago |
| `proc atualiz` | Processo de regularização em andamento |
| `hab` | Habite-se (certificado de conclusão da obra) |

---

## Abreviaturas de Localização

| Abreviatura | Significado |
|-------------|-------------|
| `PG` / `Pra. Gde.` | Praia Grande |
| `SV` / `S. Vicente` | São Vicente |
| `Sto.s` | Santos |
| `Mgua` | Mongaguá |
| `BX Santista` | Baixada Santista (região) |
| `qd do mar` | Quadras do mar (ex: "3 qd do mar" = 3 quadras) |

## Transformando Ficha em Copy — Guia Rápido

**Ficha bruta:**
> `Apto 2d 1s 1vg arm plan coz amer vara 72m² Caiçara PG R$310k FGTS ac financia`

**Copy humanizada:**
> Apartamento de 2 dormitórios com suíte, varanda e cozinha integrada. 72m² no Caiçara, Praia Grande. R$ 310.000 — aceita FGTS e financiamento pela Caixa.

> 
> Apartamento de 2 dormitórios com suíte e cozinha americana.
> R$ 310.000 | FGTS aceito | Financiamento Caixa disponível.
