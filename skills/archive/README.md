## Por que foram arquivadas?

Este repositório é um fork de [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills), adaptado para o contexto imobiliário PT-BR da Rayanne Gama Imóveis. As skills desta pasta foram desenvolvidas para produtos SaaS e mercados B2B/tech em inglês, e não se aplicam ao negócio imobiliário brasileiro.

A decisão de arquivamento está registrada em [adr/ADR-0005-archiving-generic-skills.md](../../adr/ADR-0005-archiving-generic-skills.md).
