# Vision — Rayanne Gama Imóveis × Automab.dev

## Objetivo

Construir um sistema de enablement de marketing para um agente de IA especializado no contexto imobiliário brasileiro, derivado do repositório `coreyhaines31/marketingskills`, com skills em PT-BR, integradas ao funil real de negócio da Rayanne Gama Imóveis.

## O que este projeto é

- Um fork localizado e especializado de um repositório open-source de marketing skills para agentes de IA
- Um sistema documentado, versionado, testado e mensurável
- Uma base de enablement que cresce junto com o negócio da imobiliária

## O que este projeto não é

- Uma coleção solta de prompts sem governança
- Um substituto para estratégia — ele operacionaliza a estratégia
- Um projeto de tradução — é uma reescrita com intenção imobiliária PT-BR

## Escopo inicial (Ondas 1–6)

- 5 skills núcleo adaptadas: copywriting, social content, paid ads, SEO local, analytics tracking
- Contexto mestre da Rayanne Gama Imóveis completo
- Integração com GA4, Meta Ads, Google Ads, WhatsApp e CRM
- Piloto de 4 semanas com métricas de funil

## Stack de referência

- Agente: Claude / OpenAI via Automab.dev
- Automação: n8n (Docker, Redis, PostgreSQL)
- Hosting: Vercel + Supabase
- Mídia: Meta Ads, Google Ads
- Analytics: GA4 + Meta Pixel
- Canais: Instagram, WhatsApp, OLX, VivaReal, ZAP Imóveis
